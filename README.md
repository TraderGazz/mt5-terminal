# MT5 Terminal — монорепо

Веб-терминал — визуальная копия мобильного приложения MetaTrader 5 (iOS, светлая тема).
Мобильная PWA (дизайн принят заказчиком) + ПК-версия. Только просмотр + редактирование
данных сделок + синхронизация с MT5. Подробности — в [`docs/`](docs/).

## Структура

| Папка | Что это | Статус |
|---|---|---|
| `client/` | Мобильная PWA — React 19 + TS + Vite 7 + Tailwind 3.4 + lightweight-charts 5 | вёрстка готова, данные — моки |
| `server/` | Backend — Node.js + Express + PostgreSQL | каркас, довести до ТЗ v2 |
| `database/` | `init.sql` — схема PostgreSQL | обновить под ТЗ v2 (`deal_type`, `balance_ops`) |
| `desktop/` | ПК-версия (2 страницы) | не начата (Этап 7) |
| `platform-gate/` | Страница выбора платформы | не начата (Этап 6) |
| `docs/` | ТЗ, план, спецификация дизайна | — |
| `design/` | Эталонные скриншоты принятой версии | ⏳ ждём от заказчика |

## Запуск (разработка)

```bash
npm install          # ставит зависимости во всех воркспейсах
npm run dev          # client (Vite :3000) + server (Express :4000) параллельно
npm run dev:client   # только фронт
npm run dev:server   # только backend
```

Backend без PostgreSQL тоже стартует: `/api/health` и `/api/quotes` работают,
data-роуты отвечают `503`.

## Правила проекта

1. **Дизайн заморожен.** Перед правками вёрстки — читать `docs/DESIGN_SPEC_MT5.md`.
   При подключении реальных данных вёрстка не меняется, меняется только источник данных.
2. **Моки не удалять.** Переключение источника — флагом `VITE_DATA_SOURCE=mock|api`.
3. Коммит после каждого завершённого пункта плана.
4. После каждого этапа — сверка экранов со скриншотами из `design/`.
