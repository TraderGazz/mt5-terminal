# platform-gate/ — страница выбора платформы (Этап 6)

Пока не начата. Появится на Этапе 6 плана.

Отдельная лёгкая статичная страница (без React). Открывается в новой вкладке
по кнопке «Скачать мобильную версию МТ5» из раздела «Мой кабинет» на сайте заказчика.
Два варианта: «Веб-версия для телефона» → мобильная PWA; «Веб-версия для ПК» → ПК-версия.
Размещается в корне купленного домена (или `/terminal`).
