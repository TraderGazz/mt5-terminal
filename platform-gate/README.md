# platform-gate/ — страница выбора платформы (Этап 6)

Одностраничная статика (без сборки) — `index.html`, всё внутри одного файла.
Открывается в новой вкладке по кнопке «Скачать мобильную версию МТ5» из «Мой
кабинет» на my-alfaforex.ru.

- Две карточки: «Веб-версия для телефона» → `/mobile`, «Веб-версия для ПК» → `/pc`.
- Автоопределение устройства — только подсветка карточки + подсказка, без
  принудительного редиректа.
- Стиль — палитра принятого дизайна MT5 (белый, акцент #007AFF, системный шрифт).

## Размещение

Корень купленного домена (или `/terminal`). Ссылки `/mobile` и `/pc` настраиваются
в nginx на Этапе 8:
- `/` или `/terminal` → этот `index.html`
- `/mobile` → мобильная PWA (`client/dist`)
- `/pc` → ПК-версия (`desktop/dist`)
