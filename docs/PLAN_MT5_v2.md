## 2. Целевая архитектура

```
   Мобильная PWA            ПК-версия (2 стр.)         Страница выбора платформы
        │                        │                            (статика)
        └──────────┬─────────────┘
                   │  HTTPS: REST + WebSocket
        ┌──────────▼───────────────────────────┐
        │  Наш backend (Node.js + Express)     │
        │  + WebSocket-хаб (fan-out на клиентов)│
        │  /api/auth /api/account /api/positions│
        │  /api/history /api/candles /api/quotes│
        │  /api/trades(PATCH) /api/admin /api/sync│
        └───────┬───────────────────┬───────────┘
        ┌───────▼──────┐   HTTP+WS   ▼ :8890
        │  PostgreSQL  │   ┌────────────────────────────┐
        │  (кэш+правки) │   │  SocketBridgeEA (робот MT5)│
        └──────────────┘   │  /v1/account /v1/order/list│
                           │  /v1/history/* /v1/quote   │
                           │  WS: track/prices, ohlc,   │
                           │      orders (события сделок)│
                           └──────────────┬─────────────┘
                                          │ MQL5 API
                                  ┌───────▼────────┐
                                  │ MetaTrader 5   │  (Docker: Debian+Wine+MT5+VNC)
                                  │ счёт заказчика │  на сервере Timeweb, 24/7
                                  └────────────────┘

   Автообмен (Этап 5):  backend ──HTTPS POST баланс──▶ my-alfaforex.ru
```

**Ключевые принципы:**
- **MT5 работает на сервере**, а не на ПК заказчика/исполнителя. Контейнер 24/7,
  `restart: unless-stopped`.
- **Наш backend — единственный потребитель EA.** Клиенты терминала подключаются к
  нашему WebSocket-хабу, а не к EA напрямую (EA держит подписку на одно соединение).
- **PostgreSQL — источник правды для терминала.** EA даёт live-поток; мы пишем его в
  БД. Терминал читает из БД → работает, даже когда MT5 офлайн. Отредактированные
  сделки (`is_edited=TRUE`) при обновлении из MT5 не перезатираются.
- **Терминал — только просмотр.** Торговые эндпоинты EA (`/v1/order`,
  `/v1/order/close`, `/v1/order/modify`) НЕ подключаем.
- Моки остаются, переключение `VITE_DATA_SOURCE=mock|api`.

## 3. MT5-мост: детали (папка `mt5/`)

Основано на github.com/mobjoy0/mt5-bridge (MIT). В наш репозиторий вендорим:
- `mt5/container/` — Docker-образ Debian+XFCE+Wine+MT5+NoVNC, с предустановленным
  `SocketBridgeEA.ex5`. Первый запуск сам ставит Wine и MT5.
- `mt5/ea/` — исходники EA (MQL5) для пересборки/аудита.
- Корневой `docker-compose.yml` — сервис `mt5` + наши сервисы + PostgreSQL.

**Что отдаёт EA (порт 8890):**
| REST | Назначение |
|---|---|
| `GET /v1/account` | баланс, средства, маржа, свободная маржа, equity |
| `GET /v1/order/list` | открытые позиции + отложенные ордера |
| `GET /v1/history/orders?mode=positions\|orders\|deals&from_date&to_date` | история |
| `GET /v1/history/prices?symbol&time_frame&from_date&to_date` | свечи |
| `GET /v1/quote?symbol=EURUSD` | котировка bid/ask |
| WS `track/prices` | live bid/ask |
| WS `track/ohlc` | live свечи |
| WS `track/orders` | **события открытия/закрытия сделок** |

**Правки к репозиторию (нюансы варианта А):**
1. Персистентность: WINEPREFIX `/root/.mt5` вынести в постоянный том, иначе логин и
   профиль слетают при пересборке контейнера.
2. Порт 8890 наружу НЕ публикуем — только внутренняя сеть Docker (backend ↔ mt5).
3. NoVNC 6080 — только по SSH-туннелю, не в интернет.
4. MT5: сохранить пароль, автозапуск EA из профиля, отключить лишние окна.
5. Мониторинг: если EA молчит > N сек — алерт (Telegram/почта), фронт показывает
   «данные могут быть неактуальны» (но не ломается).

**Разовая ручная настройка (~30–60 мин, один раз):** вход в счёт через VNC,
EA на график EURUSD, «Автоторговля» вкл.

**Риски:** RAM (Wine+MT5 ≈ 2 ГБ, сервер от 4 ГБ); автообновления MT5; возможная
блокировка входа брокером с IP дата-центра (проверить в первую очередь) → запасной
вариант Б (MT5 на Windows-VPS/машине заказчика).

## 7. Риски и обход

1. **Брокер блокирует вход с IP дата-центра** → проверяем первым делом; запас —
   вариант Б (MT5 на Windows-VPS / машине заказчика) или прокси.
2. **Wine+MT5 в контейнере капризны, RAM** → сервер от 4 ГБ, снапшоты тома с
   настройками, мониторинг, готовность повторить настройку через VNC (~15 мин).
3. **Нет доступа к счёту MT5** → всё кроме Этапа 4 делается на моках и демо-счёте;
   мок-мост повторяет формат реального EA, переключение — сменой конфига.
4. **MT5 офлайн** → терминал показывает последнее из БД + статус «неактуально».
5. **my-alfaforex.ru не готов принимать баланс** → Этап 5 откладывается, остальное
   сдаётся; либо мок-приёмник на нашей стороне для демонстрации.
6. **PWA-кэш** → при деплое network-first для HTML + versioned cache.
