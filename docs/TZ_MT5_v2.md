### Версия 2.0 | 08.09.2026 | Дизайн мобильной версии ПРИНЯТ заказчиком

## 1. ОБЩИЕ ПОЛОЖЕНИЯ

### 1.1. Цель проекта
Разработка веб-терминала — визуальной копии официального приложения MetaTrader 5 — в двух версиях:
- **Мобильная PWA** (iPhone, Safari, установка на экран «Домой») — **дизайн реализован и принят заказчиком**;
- **ПК-версия** — 2 страницы (состав уточняется, предположительно Торговля и История).

Назначение: просмотр котировок, графиков, открытых позиций, истории сделок с возможностью редактирования данных, автоматическая синхронизация с MT5, автообмен данными с существующими сайтами.

### 1.2. Пользовательский флоу (новое, 08.09.2026)
```
Сайт заказчика → «Мой кабинет» → кнопка «Скачать мобильную версию МТ5»
   → новая вкладка браузера: страница выбора платформы
       ├── «Веб-версия для телефона» → мобильная PWA
       └── «Веб-версия для ПК»      → ПК-версия (2 страницы)
```
- Кнопка размещается в разделе «Мой кабинет» на существующем сайте заказчика (готовый сниппет предоставляется исполнителем, либо внедряется исполнителем при наличии доступа).
- Страница выбора платформы открывается **в новой вкладке**, содержит два варианта: телефон / ПК.
- Весь комплекс размещается на **домене, купленном заказчиком** (подключение домена — в зоне ответственности исполнителя, DNS-записи предоставляет/вносит заказчик по инструкции).

### 1.3. Тип решения
- Мобильная версия: PWA, Safari → Поделиться → На экран «Домой», полноэкранный режим без адресной строки.
- ПК-версия: обычный адаптивный веб-сайт для десктопных браузеров.
- **Не нативное приложение iOS/Android, не публикуется в App Store.**

### 1.4. Технологии
| Компонент | Технология |
|-----------|------------|
| Frontend (мобильный) | React 19 + TypeScript + Vite + Tailwind CSS |
| Frontend (ПК) | React + Vite (та же дизайн-система, десктопная раскладка) |
| Графики | TradingView Lightweight Charts 5 |
| Backend | Node.js + Express |
| База данных | PostgreSQL (основная) + SQLite (кэш, опционально) |
| Сервер | Timeweb Cloud (существующий аккаунт) |
| Домен | Куплен заказчиком; SSL — Let's Encrypt |
| PWA | Service Worker + manifest.json |
| Связь с MT5 | MetaTrader5 Python API |
| Автообмен | REST API между сайтами |

## 2. ВИЗУАЛЬНЫЙ СТИЛЬ

### 2.1. Общий стиль (зафиксирован по принятой мобильной версии)
- **Светлая тема**, как в официальном iOS-приложении MT5.
- Шрифт: системный iOS (San Francisco / -apple-system).
- Фон страниц: белый `#FFFFFF`; групповой фон (Настройки): `#EFEFF4`.
- Текст: чёрный `#000000`, вторичный серый `#8E8E93`.
- **Прибыль / положительные значения: синий `#007AFF`** (как в оригинале MT5 для iOS).
- **Убыток / отрицательные значения: красный `#FF3B30`.**
- Акцент (вкладки, кнопки, переключатели): синий `#007AFF`.
- Разделительные линии в списках истории/периода: `#C6C6C8`.
- Адаптация под iPhone: ширина колонки 375–430px.
- Нижнее меню: фиксированное, 5 вкладок.
- Полная спецификация (точные размеры шрифтов, отступы, высоты строк, состояния) — в документе `DESIGN_SPEC_MT5.md` и на эталонных скриншотах (`design/`). **Спецификация является частью настоящего ТЗ.**

### 2.2. Нижнее меню (5 вкладок)
- Тонкие линейные иконки (stroke ~1.7–2), как в оригинале MT5 iOS.
- Неактивная вкладка: тёмный `#1C1C1E`.
- Активная вкладка: синий `#007AFF` на сером фоне-пилюле `rgba(120,120,128,0.16)`.
- **Исключение: активная вкладка «Торговля» — красная `#FF3B30`** (особенность оригинала, зафиксирована заказчиком по скриншоту).

| Вкладка | Активное состояние |
|---------|--------------------|
| Котировки | Синяя иконка+текст |
| Чарт | Синяя |
| Торговля | **Красная** |
| История | Синяя |
| Настройки | Синяя |

### 2.3. Логотип и PWA
- Логотип MetaTrader 5 — товарный знак, без письменного разрешения MetaQuotes не используется. По умолчанию: нейтральная иконка (уже реализована). Если заказчик предоставит свой логотип — замена.
- Название под иконкой: «MetaTrader 5» (или по логотипу заказчика).
- Splash screen: белый фон + иконка по центру. Status bar iOS: светлый.

## 3. СТРУКТУРА И СТРАНИЦЫ (мобильная PWA — реализовано, зафиксировано)

### Страница 1. Авторизация
- Шапка: стрелка назад, заголовок «Авторизация»; логотип брокера; поля Сервер/Логин/Пароль; «Запомнить пароль»; «Забыли пароль?»; кнопка «Войти».
- Демо-режим: любой логин + пароль «demo» (до подключения реальной авторизации).

### Страница 2. Чарт
- Свечной график, таймфреймы M1–D1, pinch-зум, прокрутка, Bid/Ask в шапке.
- **Индикаторы (добавлено по требованию заказчика): Ichimoku Kinko Hyo (9/26/52) + Fractals** — рассчитываются от реальных данных свечей на клиенте (Tenkan — красная, Kijun — синяя, Senkou A/B — пунктир со сдвигом +26, Chikou — зелёная со сдвигом −26, фракталы — серые стрелки). При подключении реального источника данных логика индикаторов сохраняется.

### Страница 3. Котировки
- Белый фон; список символов **без разделительных линий** между строками.
- Компактная типографика: символ 14px semibold, цифры цен уменьшенные (крупные пипсы выделены размером, как в оригинале), строка изменения 12px, время/спред 11px.
- Изменение в %: синий (плюс) / красный (минус).

### Страница 4. Торговля
- Шапка: плавающая прибыль/убыток крупным шрифтом (20px semibold, красный при минусе).
- Блок счёта: Баланс / Средства / Маржа / Свободная маржа / Уровень маржи — значения полужирные (font-medium).
- Серая плашка-разделитель «Позиции» (фон `#F8F8F8`, высота ~29px).
- Список позиций, только просмотр. Пометок «(изм.)» нет.

### Страница 5. История
- Открывается **проскролленной вниз** (итоги видны сразу, как в оригинале).
- Вкладки: **Позиции | Ордера | Сделки** (вкладки «Баланс» НЕТ — удалена по требованию заказчика).
- Слева вверху — кнопка сортировки (иконка как в оригинале): всплывающее меню «СОРТИРОВКА»: По умолчанию ✓ / Символ / Тикет / Тип / Объем / Время открытия / Время закрытия / Прибыль. Сортировка рабочая.
- Справа вверху — значок часов → страница выбора периода (Стр. 6).
- Итоги внизу (в этом порядке): **Депозит → Снятие → Прибыль → CFD → Своп → Комиссия → Баланс**.
  - Разделительные линии: над «Депозит» и под «Баланс».
  - Строки «Снятие» и «CFD»: за весь период — всегда; за выбранный период — только если в нём были соответствующие операции (ненулевые).
  - Значения итогов полужирные.
- Пометки «(изм.)» **не отображаются** (требование заказчика; флаг is_edited хранится в БД без вывода в UI).

### Страница 6. Выбор периода истории
- Строки: Символ (Все символы); Сегодня / Последняя неделя / Последний месяц / Последние 3 месяца / **Последние 6 месяцев (по умолчанию)** / Последний год / Выбрать период.
- **Разделительная линия между каждой строкой.**
- Кнопка «Создать торговый отчёт» — подпись соответствует выбранному периоду (по умолчанию «Последние 6 месяцев»); экспорт HTML/CSV.

### Страницы 7–8. Детали и редактирование сделки
- Детали: таблица полей (ордер/позиция/сделка, время, тип, символ, цена, объём, прибыль, **CFD**, своп, комиссия).
- Редактирование: прибыль, своп, комиссия, комментарий, время/цена открытия и закрытия; Сохранить/Отмена; в БД ставится is_edited=TRUE (без пометки в UI).

### Страница 9. Настройки
- Заголовок «Настройки» статичен при прокрутке.
- Групповой серый фон `#EFEFF4`, карточки inset-grouped (белые, скруглённые, с отступами по краям).
- Профиль (ФИО, компания, счёт, сервер) + 11 пунктов с иконками в системных цветах iOS (зелёный #34C759, голубой #5AC8FA, оранжевый #FF9500, красный #FF3B30, синий #007AFF, серый #8E8E93; тонкие контурные глифы): Новый счёт, Почта, Новости, Tradays, Чат и сообщения, Сообщество трейдеров, MQL5 Algo Trading, OTP, Интерфейс, Чарты, Журнал.
- Пункты без функционала — заглушки «В разработке».

### Страница 10. Админ-панель (отдельная, /admin)
- Отдельный вход (демо: admin/admin). Разделы: Пользователи (admin/trader/viewer), Лог импортов, Редактирование баланса/маржи, Настройки автообмена, Экспорт отчёта HTML/CSV.

### Страница 11. Интеграция в АльфаФорекс (упрощённые 11a «Торговля», 11b «История»)
- Остаётся в силе по прежнему ТЗ (встраивание в существующий сайт).

### Страница 12 (НОВАЯ). Выбор платформы
- Отдельная страница на домене заказчика, открывается в новой вкладке по кнопке «Скачать мобильную версию МТ5» из «Мой кабинет».
- Два варианта: «Веб-версия для телефона» → мобильная PWA; «Веб-версия для ПК» → ПК-версия.
- Желательно автоопределение устройства (подсказка, без жёсткого редиректа).

### Страницы 13 (НОВЫЕ). ПК-версия (2 страницы)
- Состав: **2 страницы — предположительно Торговля и История (подтвердить с заказчиком)**.

## 4. ФУНКЦИОНАЛЬНЫЕ МОДУЛИ

### 4.1. Котировки и график
- Источник: бесплатный API (Yahoo Finance / Alpha Vantage) в режиме `external`; позже — MT5 (`mt5`); `mock` для разработки. Переключение через конфиг.
- Символы: EURUSD, USDRUB, XAUUSD, GBPUSD и др. (финальный список — от заказчика).
- Обновление: настраиваемый интервал (по умолчанию 5–10 сек; технически возможно от 1 сек, упор — в лимиты API).
- График: свечи M1–D1, pinch-зум; **индикаторы Ichimoku (9/26/52) + Fractals — входят в объём** (уже реализованы).

### 4.2. Загрузка и синхронизация с MT5
Без изменений от v1: авто-синк через MetaTrader5 Python API (cron 5 мин), автоподгрузка при закрытии сделок, ручная загрузка HTML-отчёта с парсером, редактирование при загрузке. Таблица `trades` — как в v1, **плюс поле `deal_type`** (значения: buy/sell/balance/withdrawal/cfd...) для строк «Снятие» и «CFD» в итогах.

### 4.3. Редактирование сделок
- Все числовые и текстовые поля редактируемы; флаг `is_edited=TRUE` в БД.
- **Пометка «(изм.)» в интерфейсе НЕ выводится** (изменение требования от 08.09.2026).

### 4.4. Автообмен с сайтами (Русинвест ↔ АльфаФорекс)
- Без изменений от v1 (основное направление Русинвест → АльфаФорекс, cron 5 мин, лог в админке). **Актуальность подтвердить у заказчика.**

### 4.5. PWA
- manifest.json, service worker, iOS-мета-теги. 
- **Требование к продакшн-SW:** версионирование кэша (network-first для HTML), чтобы обновления доходили до установленных копий.

## 5. АРХИТЕКТУРА

### 5.1. Сервер
- Timeweb Cloud, Ubuntu 22.04 LTS, 2+ CPU / 4 GB RAM / 50 GB NVMe. Node.js (PM2/systemd), PostgreSQL, Python 3 + MetaTrader5, Nginx.

### 5.2. Домен и SSL (обновлено)
- **Домен куплен заказчиком.** Требуется: имя домена + внесение DNS-записей (A-запись → IP сервера; заказчик вносит сам по инструкции или даёт доступ к DNS-панели).
- Схема (согласовать): корень/`/terminal` — страница выбора платформы; `m.домен` или `/mobile` — мобильная PWA; `pc.домен` или `/pc` — ПК-версия; `/api` — backend.
- SSL: Let's Encrypt (certbot), автообновление. HTTPS обязателен для PWA.

### 5.3. Структура проекта
```
/var/www/terminal/
├── client/          # Мобильная PWA (готова, дизайн принят)
├── desktop/         # ПК-версия (2 страницы)
├── platform-gate/   # Страница выбора платформы
├── server/          # Node.js + Express
│   ├── routes/      # auth, trades, quotes, upload, sync, admin, report
│   ├── services/    # mt5-parser.js, mt5-api.js, sync-service.js, quote-provider.js
│   └── scripts/     # mt5-sync.py
└── database/        # init.sql
```
