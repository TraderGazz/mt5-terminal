# desktop/ — ПК-версия (Этап 7)

React 19 + Vite + Tailwind, тот же backend, что и мобильная версия. Только
просмотр. Моков нет — всегда работает с реальным API.

Заявка заказчика: «Торговля» и «История» — точная копия оригинального
десктопного MT5 (референс — реальные скриншоты терминала). В оригинале это
НЕ отдельные страницы, а вкладки одной нижней панели, которая всегда
находится под графиком — так же сделано и здесь: один экран (TerminalPage),
график сверху (Chart), под ним закреплённая панель с вкладками (BottomPanel:
«Торговля» — открытые позиции, «История» — закрытые сделки; остальные
вкладки оригинала показаны для вида, но не заказывались и не работают).

```
desktop/
├── src/
│   ├── api/        http / auth / ws / rest — тонкий клиент к /api и /ws
│   ├── components/ Shell (шапка + строка счёта), Chart (свечи), BottomPanel (вкладки Торговля/История)
│   ├── lib/        format.ts — money/price/dt/lots как в оригинале MT5
│   └── pages/      Login, Terminal (Chart + BottomPanel)
└── vite.config.ts  dev :3100, прокси /api и /ws → :4000
```

Пока не сделано (не входило в этот проход): инструменты рисования на
графике (трендлинии/Фибоначчи — это ручная разметка самого трейдера на
скриншотах-референсах, не часть дизайна для копирования), переключение
символа, Market Watch, панель инструментов/меню в духе нативного Windows-
приложения, контекстное меню по правому клику на строке.

## Запуск

```bash
npm run dev:desktop        # только ПК-версия (:3100)
npm run dev:all            # client :3000 + desktop :3100 + server :4000
```
Вход: `admin` / `admin123` (как и в мобильной).

## Дизайн

Пока функциональный черновик на палитре MT5 (белый фон, акцент #007AFF, прибыль
синяя, убыток #FF3B30). Финальная десктопная раскладка — после согласования
состава и вида страниц с заказчиком.

## Размещение (Этап 8)

`pc.домен` или `/pc` → `desktop/dist` (nginx).
